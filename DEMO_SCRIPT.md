# 4-Minute Hackathon Demo Script

## 0:00–0:30 — The question
Open `/login`. Say: “When something goes wrong, how does the right hero get there fastest?” Show the three portals and explain that the workflow is one connected accountability chain.

## 0:30–1:10 — Civilian report
Create a civilian account. Submit a high-severity Security report near KIIT Square with location and details. Point out the immediate timeline entry and live event indicator.

## 1:10–2:15 — Officer intelligence
Sign in to Control Room. Open the new report; acknowledge it. Explain the recommendation score while comparing Security Alpha against medical/fire/technical teams. Select Security Alpha as primary and dispatch it. Show the two-minute acknowledgement window and incident channel.

## 2:15–3:05 — Hero response
Sign in as Security Alpha. Show availability/location controls. Accept the mission, mark en route, send “Reached north gate” in the incident channel, and resolve it.

## 3:05–3:35 — Closed loop
Return to the civilian portal. Show `RESOLVED`, the actor-stamped timeline and shared message. Emphasize that no manual refresh was required; SSE has a polling fallback.

## 3:35–4:00 — Technical depth
Show the Bhubaneswar GIS, KIIT hotspot, patrol geofence comparison and fallback escalation. Close with server-side role enforcement, explainable matching, persistent audit history and the clear prototype-data label.
